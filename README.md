# shooq — portfolio

My personal portfolio: bilingual (Arabic / English), light & dark, built by hand with HTML, CSS and JavaScript.

## Update the daily log
Edit `log.json` — add a new entry at the top of `entries`, and change `status` for the "Now:" line.
Tip: open the site with `#edit-log` at the end of the URL to get a form that writes the entry for you.

## Add a LinkedIn post
On LinkedIn: ••• → Embed this post → copy the `src` link, then add it to `linkedin.json`:
`{ "embed": "https://www.linkedin.com/embed/feed/update/urn:li:share:…?collapsed=1", "h": 640 }`
